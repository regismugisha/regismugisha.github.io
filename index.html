Cybersecurity IoT

Smart Home Security Fortress

Situation

Consumer IoT devices were riddled with vulnerabilities — default credentials, unencrypted traffic, and exposed APIs. Over 70% of smart home breaches exploited these gaps.

Task

Design and build an end-to-end secure IoT ecosystem for smart homes that detects, prevents, and responds to threats in real time.

Action

Engineered a custom firmware with mutual TLS authentication, deployed a local NIDS (Network Intrusion Detection System) on a Raspberry Pi gateway, built a real-time dashboard with MQTT + Node.js, and implemented automated anomaly detection using Python ML models running at the edge.

Result

Reduced attack surface by 94%. Detected 100% of simulated intrusion attempts within 1.2 seconds. Open-sourced the firmware, garnering 800+ GitHub stars in the first month.

02
Machine Learning Full-Stack

AI-Powered Network Threat Analyzer

Situation

Enterprise SOC teams were drowning in false positives — spending 40% of their time triaging alerts that weren't real threats. Alert fatigue was causing analysts to miss genuine incidents.

Task

Build an intelligent system that classifies network traffic, identifies threats with high precision, and presents actionable intelligence through a modern dashboard.

Action

Trained a Random Forest + LSTM hybrid model on the CICIDS2017 and UNSW-NB15 datasets. Engineered a Python/Flask API backend serving real-time predictions. Built a React + D3.js frontend for live traffic visualization. Containerized everything with Docker and deployed on AWS ECS.

Result

Achieved 97.3% detection accuracy with a 0.8% false positive rate (down from industry average of ~15%). Reduced mean-time-to-detect from 4 hours to under 30 seconds. Processing 10K+ events/sec in production.

03
IoT Robotics Smart Home

IoT Robotics & Smart Home Systems

Situation

Most smart home products were expensive, closed-source, and fragmented — devices from different brands couldn't talk to each other, and users had to juggle multiple apps to control their home.

Task

Build a complete, open smart home automation system that unifies all devices under one platform — with remote control, automation routines, and a clean, intuitive interface.

Action

Developed a full-stack smart home system using ESP32 microcontrollers + MQTT for device communication. Built a Node.js backend hub and a custom web dashboard for real-time control and monitoring. Integrated voice control, motion sensing, and energy tracking, with automation routines for lighting, climate, and security. Added ML-based anomaly detection to flag unusual power usage.

Result

Created a fully working smart home covering lighting, climate, and security. Reduced manual home control by 90% through automation routines. All devices operate seamlessly over open protocols with a single dashboard. Project won 1st place at university IoT hackathon.
